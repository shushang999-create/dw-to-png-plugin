# DWTOpng - 飞书多维表格转PNG插件

## 项目概述

DWTOpng 是一款功能强大的飞书多维表格边栏插件，旨在将表格数据转换为高质量的PNG图片，实现数据的可视化导出与分享。该插件支持丰富的配置选项和主题定制，适用于各种场景下的数据展示需求。

## 核心功能

- 📊 **数据可视化**：将表格数据转换为美观的PNG图片
- 🎨 **双主题支持**：提供浅色和深色两种主题，适配不同使用场景
- ⚙️ **灵活配置**：可自定义表头显示、最大行数、单元格尺寸等参数
- 🔄 **实时同步**：自动监听表格数据变化，保持导出内容与源数据一致
- 📱 **响应式设计**：适配不同屏幕尺寸，确保在各种设备上正常使用
- 🌍 **多语言支持**：支持中文字段类型显示，提升中文用户体验
- 📦 **多种部署方式**：支持本地开发、构建部署和可执行文件运行

## 安装指南

### 环境要求

- Node.js 16+
- npm 或 yarn 包管理器

### 安装步骤

```bash
# 克隆仓库
git clone <仓库地址>
cd DWTOpng

# 安装依赖
npm install
```

## 快速开始

### 1. 本地开发模式

```bash
npm run dev
```

启动后访问 `http://localhost:5173` 进行开发和测试。

### 2. 在飞书多维表格中使用

1. 打开任意飞书多维表格
2. 点击 `插件` 展开插件面板
3. 点击 `自定义插件`，然后点击 `+新增插件`
4. 在输入框中填入本地开发地址 `http://localhost:5173` 后点击 `确定`
5. 插件将自动加载，开始使用导出功能

### 3. 构建生产版本

```bash
npm run build
```

构建完成后，`dist` 目录包含可部署的静态文件。

### 4. 启动本地服务器

```bash
npm start
```

或使用可执行文件（Windows）：

```bash
./DWTOpng.exe
```

## 字段格式管理

### 功能概述

已成功实现了图片生成过程中字段格式的读取、展示和调整功能。用户现在可以：

1. **读取字段信息**：通过API自动读取表格中的所有字段信息
2. **可视化展示**：在界面上展示每个字段的类型和当前格式
3. **灵活调整**：为每个字段单独设置格式，包括字体、颜色、对齐方式等
4. **实时预览**：格式调整立即在表格预览中生效
5. **导出应用**：格式设置会应用到最终的PNG图片导出

### 支持的格式选项

#### 基础格式
- **字体大小**: 8-24px
- **字体粗细**: 正常/粗体
- **文字颜色**: 颜色选择器
- **背景颜色**: 颜色选择器
- **对齐方式**: 左对齐/居中/右对齐
- **内边距**: 数值调整
- **边框**: 显示/隐藏，边框颜色
- **显示字段类型**: 在表头中显示字段类型标签

#### 特殊字段格式

##### 数字字段
- 整数格式
- 小数格式（1-3位）
- 千位分隔符
- 百分比格式

##### 日期字段
- `yyyy-MM-dd` (2024-01-01)
- `yyyy/MM/dd` (2024/01/01)
- `MM-dd` (01-01)
- `MM/dd/yyyy` (01/01/2024)
- `dd/MM/yyyy` (01/01/2024)
- `yyyy-MM-dd HH:mm` (2024-01-01 12:00)
- `yyyy/MM/dd HH:mm` (2024/01/01 12:00)

### 使用方法

1. **打开字段格式管理器**
   - 点击顶部工具栏的"字段格式"按钮
   - 格式管理器会展开显示

2. **设置全局格式**
   - 在全局设置区域调整常用格式
   - 设置会应用到所有字段

3. **调整单个字段**
   - 在字段列表中找到目标字段
   - 调整该字段的特定格式
   - 可以点击"重置"恢复默认格式

4. **预览效果**
   - 格式调整会立即在下方表格中显示
   - 可以实时查看格式效果

5. **导出PNG**
   - 点击"导出为PNG"按钮
   - 导出的图片会包含所有格式设置

### 特殊字段自动格式化

在图片生成过程中，对于字段名称包含以下关键词的字段，会自动应用两位小数格式化：
- 成材率
- 非定尺率
- 负公差

#### 格式化规则

1. **数字类型**：保留两位小数（四舍五入）
   - `0.8567` → `0.86`
   - `-0.0123` → `-0.01`

2. **字符串数字**：尝试转换为数字后格式化
   - `"0.9234"` → `0.92`

3. **非数字值**：显示"/"
   - `null` → `/`
   - `"abc"` → `/`
   - `undefined` → `/`

## 常见问题解答

### Q: 导出失败怎么办？
A: 检查浏览器控制台错误信息，确保网络连接正常，尝试刷新页面重新加载。

### Q: 图片不完整怎么办？
A: 表格内容过多可能导致图片截断，可以减少最大行数或分批导出。

### Q: 样式显示异常？
A: 清除浏览器缓存，确保使用最新版本的插件。

### Q: 字段类型显示不正确？
A: 确保使用的是最新版本的飞书多维表格SDK。

### Q: 如何生成可执行文件？
A: 运行 `npm run build-exe` 命令生成Windows可执行文件。

### Q: 如何打包插件？
A: 运行 `npm run package` 命令打包插件，生成可部署的插件包。

## 边栏插件开发指南

### 插件开发概述

边栏插件是多维表格推出的灵活、便捷的开放能力，开发者可通过编程实现自定义功能，扩展核心平台能力。本插件基于React + TypeScript开发，使用飞书多维表格JS SDK进行数据交互。

### 开发环境准备

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

### 在飞书多维表格中使用

1. 打开任意飞书多维表格
2. 点击 `插件` 展开插件面板
3. 点击 `自定义插件`，然后点击 `+新增插件`
4. 在输入框中填入本地开发地址 `http://localhost:5173` 后点击 `确定`
5. 插件将自动加载，开始使用导出功能

### 数据模型

多维表格的数据结构与常见的关系型数据库基本概念相通，核心概念包括：
- Base (多维表格)
- Table (数据表)
- Field (字段)
- Record (记录)
- Cell (单元格)
- View (视图)

### 核心API使用

```typescript
// 获取当前激活的表格
const table = await bitable.base.getActiveTable();

// 获取字段元数据列表
const fieldMetaList = await table.getFieldMetaListByType<ICurrencyFieldMeta>(FieldType.Currency);

// 获取记录ID列表
const recordIdList = await table.getRecordIdList();
```

### 主题支持

插件支持浅色和深色两种主题，可通过SDK监听主题变化：

```typescript
// 获取当前主题
const theme = await bitable.bridge.getTheme();

// 监听主题变化
bitable.bridge.onThemeChange((event) => {
  console.log('theme change', event.data.theme);
});
```
